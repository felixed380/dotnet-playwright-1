# QA Automation Portfolio - .NET & Playwright

Este repositorio contiene un proyecto de automatización de pruebas End-to-End (E2E) desarrollado como parte de mi portafolio profesional de QA Automation.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** C# (.NET 10)
- **Framework de Automatización:** Playwright
- **Framework de Pruebas:** NUnit
- **Patrón de Diseño:** Page Object Model (POM)
- **CI/CD:** GitHub Actions

## 🎯 ¿Qué se prueba?
Actualmente, el proyecto cuenta con pruebas automatizadas para el flujo de inicio de sesión en el sitio de práctica [Sauce Demo](https://www.saucedemo.com).

## 🚀 Cómo ejecutar el proyecto localmente

1. Clona este repositorio.
2. Asegúrate de tener instalado el SDK de .NET 10.
3. Restaura las dependencias:

   dotnet restore
